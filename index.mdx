Welcome to NEAR AI Cloud — a private, verifiable AI inference platform that runs leading AI models inside Trusted Execution Environments (TEEs). Your prompts and outputs are never exposed to the infrastructure operator, any third party, or NEAR AI itself. Access every model through a single OpenAI-compatible API so you can integrate without rewriting your existing code.

## Why NEAR AI Cloud?

<CardGroup cols={2}>
  <Card title="Hardware-Level Privacy" icon="shield-check">
    Every inference request runs inside a TEE. Your prompts and outputs are encrypted in memory — inaccessible to the host OS, hypervisor, or cloud provider.
  </Card>
  <Card title="Unified OpenAI-Compatible API" icon="cloud">
    One endpoint, one key format, and full compatibility with the OpenAI SDKs you already use. Switch models without changing your integration.
  </Card>
  <Card title="Pay-As-You-Go" icon="credit-card">
    Add credits to your account and pay only for the tokens you consume. No subscriptions, no seat fees, no minimum commitments.
  </Card>
  <Card title="Verifiable Attestation" icon="file-check">
    Every TEE session produces a signed attestation report you can verify independently. Confirm that your request ran on genuine confidential hardware.
  </Card>
</CardGroup>

## Get Up and Running

<Steps>
  <Step title="Create your account">
    Go to [cloud.near.ai](https://cloud.near.ai) and sign up for a NEAR AI Cloud account.
  </Step>
  <Step title="Add credits">
    Open the **Credits** section in the dashboard and top up your balance to enable inference requests.
  </Step>
  <Step title="Generate an API key">
    Open the **API Keys** section, create a new key, and copy it to a secure location. You will use this key to authenticate every API call.
  </Step>
  <Step title="Make your first API call">
    Point any OpenAI-compatible client at `https://cloud-api.near.ai/v1`, set your API key as the bearer token, and send a chat completion request. See the [Quickstart](/cloud/quickstart) for ready-to-run examples in curl, Python, and JavaScript.
  </Step>
</Steps>
