Call the OpenAI Responses API with attestation and response-signature verification. JavaScript, Python, and Go use the official OpenAI clients with the Inference SDK as their transport; Rust uses the native NEAR AI client.

## Create and verify a response

Set `NEARAI_API_KEY` and choose a Responses model from the [catalog](/cloud/models).

Use `store: false` for stateless requests and leave E2EE disabled. The examples verify the response before displaying it.

<Tabs>
<Tab title="JavaScript">

Requires Node.js 24.22.1 or later.

```bash
npm install @nearai/inference-sdk openai
```

```javascript
import OpenAI from "openai";
import { InferenceClient } from "@nearai/inference-sdk/node";

const apiKey = process.env.NEARAI_API_KEY;
if (!apiKey) throw new Error("Set NEARAI_API_KEY first.");

const inferenceClient = new InferenceClient({
  apiKey,
  baseUrl: "https://cloud-api.near.ai/v1",
  e2ee: false,
});

const openai = new OpenAI({
  apiKey,
  baseURL: inferenceClient.getBaseUrl(),
  fetch: inferenceClient.fetch,
  maxRetries: 0,
});

const response = await openai.responses.create({
  model: "openai/gpt-6-astra",
  input: "Hello!",
  store: false,
});

// Verify before displaying the answer.
const verified = await inferenceClient.verifyResponse(response.id);
console.log(response.output_text);
console.log("Verified signer:", verified.signatureKind);
```

<Tab title="Python">

Requires Python 3.12 or later.

```bash
pip install nearai-inference-sdk openai
```

```python
import asyncio
import os

from openai import AsyncOpenAI
from nearai_inference_sdk import InferenceClient


async def main():
    api_key = os.environ["NEARAI_API_KEY"]

    async with InferenceClient(
        api_key,
        base_url="https://cloud-api.near.ai/v1",
        e2ee=False,
    ) as inference_client:
        async with AsyncOpenAI(
            api_key=api_key,
            base_url="https://cloud-api.near.ai/v1/",
            http_client=inference_client.http_client,
            max_retries=0,
        ) as client:
            response = await client.responses.create(
                model="openai/gpt-6-astra",
                input="Hello!",
                store=False,
            )

            # Verify before displaying the answer.
            verified = await inference_client.verify_response(response.id)
            print(response.output_text)
            print("Verified signer:", verified.signature_kind)


asyncio.run(main())
```

Requires Rust stable and Cargo.

cargo add nearai-inference-sdk

```rust
use nearai_inference_sdk::{InferenceClient, InferenceClientOptions};
use serde_json::json;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = InferenceClient::with_options(InferenceClientOptions {
        api_key: Some(std::env::var("NEARAI_API_KEY")?),
        base_url: "https://cloud-api.near.ai/v1".into(),
        e2ee: false,
        ..Default::default()
    })?;
    let response = client.create_response(json!({
        "model": r#"openai/gpt-6-astra"#,
        "input": "Hello!",
        "store": false
    })).await?;

    // Verify before displaying the answer.
    let id = response["id"].as_str().ok_or("response has no ID")?;
    let verified = client.verify_response(id).await?;
    println!("{}", response["output"]);
    println!("Verified signer: {:?}", verified.signature_kind());
    Ok(())
}
```

<Tab title="Go">

Requires Go 1.26.10 or later.

```bash
go get github.com/nearai/inference-sdk/go github.com/openai/openai-go/v3
```

```go
package main

import (
    "context"
    "fmt"
    "log"
    "os"
    "time"

    nearai "github.com/nearai/inference-sdk/go"
    "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
    "github.com/openai/openai-go/v3/responses"
)

func main() {
    if err := run(); err != nil {
        log.Fatal(err)
    }
}

func run() error {
    apiKey := os.Getenv("NEARAI_API_KEY")
    if apiKey == "" {
        return fmt.Errorf("set NEARAI_API_KEY first")
    }
    ctx, cancel := context.WithTimeout(context.Background(), 2*time.Minute)
    defer cancel()

    client, err := nearai.NewInferenceClient(nearai.InferenceOptions{
        ClientOptions: nearai.ClientOptions{
            APIKey: apiKey,
            BaseURL: "https://cloud-api.near.ai/v1",
        },
        E2EE: false,
    })
    if err != nil {
        return err
    }
    defer client.Close()

    ai := openai.NewClient(
        option.WithAPIKey(apiKey),
        option.WithBaseURL(client.BaseURL()),
        option.WithHTTPClient(client.HTTPClient()),
        option.WithMaxRetries(0),
    )
    response, err := ai.Responses.New(ctx, responses.ResponseNewParams{
        Model: "openai/gpt-6-astra",
        Input: responses.ResponseNewParamsInputUnion{OfString: openai.String("Hello!")},
        Store: openai.Bool(false),
    })
    if err != nil {
        return err
    }
    if response.ID == "" {
        return fmt.Errorf("response has no ID")
    }

    // Verify before displaying the answer.
    verified, err := client.VerifyResponse(ctx, response.ID)
    if err != nil {
        return err
    }
    fmt.Println(response.OutputText())
    fmt.Println("Verified signer:", verified.SignatureKind)
    return nil
}
```

## Receipt verification

Pass the response `id` to the verification method. Responses use Gateway signatures: they verify the bytes signed by the Gateway, not model TEE execution.

If the receipt is temporarily unavailable, retry verification with the same ID. Response records expire after 60 minutes by default, so verify before expiry or closing the client.

## Streaming

Set `stream: true` (`stream=True` in Python), read the entire stream, then verify using `event.response.id` from an event such as `response.created`. Text displayed before verification succeeds is still unverified.

See complete streaming examples for [JavaScript](https://github.com/nearai/inference-sdk/blob/main/examples/example-js/gateway/responses-openai-sdk.ts), [Python](https://github.com/nearai/inference-sdk/blob/main/examples/example-py/gateway/responses_openai_sdk.py), [Rust](https://github.com/nearai/inference-sdk/blob/main/examples/example-rs/src/bin/responses.rs), and [Go](https://github.com/nearai/inference-sdk/blob/main/examples/example-go/gateway/responses/main.go).

## API support

The SDK supports `POST /v1/responses` with JSON or streaming responses. Manage conversation history in your application; see [Stateless Responses](/cloud/guides/stateless-responses) for multi-turn conversations and function calls.

OHTTP is optional and requires Ed25519. Field E2EE and direct model endpoints are not supported for Responses.
