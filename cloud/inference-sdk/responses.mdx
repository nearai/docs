Use Inference SDK 0.2.0 to create Responses through the NEAR AI Cloud Gateway with attestation checks and explicit response-signature verification. JavaScript, Python, and Go can keep the official OpenAI SDK interface; Rust uses the native client.

## Create and verify a response

Set `NEARAI_API_KEY` in your server environment and choose an available model from the [catalog](/cloud/models). These examples require Node.js 24.22.1+, Python 3.12+, Rust stable, or Go 1.26.10+. Create a Cargo project or Go module first when starting a new Rust or Go application.

Each example sets `store: false`, disables field E2EE, and verifies the response before displaying it. Applications control inference retries; automatic retries in the official SDKs are disabled here.

```javascript
import OpenAI from "openai";
import { InferenceClient } from "@nearai/inference-sdk/node";

const apiKey = process.env.NEARAI_API_KEY;
if (!apiKey) throw new Error("Set NEARAI_API_KEY first.");

// Verify deployment evidence and the Gateway's Responses receipt.
const inferenceClient = new InferenceClient({
  apiKey,
  baseUrl: "https://cloud-api.near.ai/v1",
  e2ee: false,
});

const openai = new OpenAI({
  apiKey,
  baseURL: inferenceClient.getBaseUrl(),
  fetch: inferenceClient.fetch,
  maxRetries: 0,
});

const response = await openai.responses.create({
  model: "openai/gpt-6-astra",
  input: "Hello!",
  store: false,
});

// Verify the exact request/response bytes before displaying the answer.
const verified = await inferenceClient.verifyResponse(response.id);
console.log(response.output_text);
console.log("Verified signer:", verified.signatureKind);
```

```python
import asyncio
import os

from openai import AsyncOpenAI
from nearai_inference_sdk import InferenceClient


async def main():
    api_key = os.environ["NEARAI_API_KEY"]

    # Verify deployment evidence and the Gateway's Responses receipt.
    async with InferenceClient(
        api_key,
        base_url="https://cloud-api.near.ai/v1",
        e2ee=False,
    ) as inference_client:
        async with AsyncOpenAI(
            api_key=api_key,
            base_url="https://cloud-api.near.ai/v1/",
            http_client=inference_client.http_client,
            max_retries=0,
        ) as client:
            response = await client.responses.create(
                model="openai/gpt-6-astra",
                input="Hello!",
                store=False,
            )

            # Verify the exact bytes before displaying the answer.
            verified = await inference_client.verify_response(response.id)
            print(response.output_text)
            print("Verified signer:", verified.signature_kind)


asyncio.run(main())
```

```rust
use nearai_inference_sdk::{InferenceClient, InferenceClientOptions};
use serde_json::json;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Verify deployment evidence and the Gateway's Responses receipt.
    let client = InferenceClient::with_options(InferenceClientOptions {
        api_key: Some(std::env::var("NEARAI_API_KEY")?),
        base_url: "https://cloud-api.near.ai/v1".into(),
        e2ee: false,
        ..Default::default()
    })?;
    let response = client.create_response(json!({
        "model": r#"openai/gpt-6-astra"#,
        "input": "Hello!",
        "store": false
    })).await?;

    // Verify the exact bytes before displaying the answer.
    let id = response["id"].as_str().ok_or("response has no ID")?;
    let verified = client.verify_response(id).await?;
    println!("{}", response["output"]);
    println!("Verified signer: {:?}", verified.signature_kind());
    Ok(())
}
```

```go
package main

import (
    "context"
    "fmt"
    "log"
    "os"
    "time"

    nearai "github.com/nearai/inference-sdk/go"
    "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
    "github.com/openai/openai-go/v3/responses"
)

func main() {
    if err := run(); err != nil {
        log.Fatal(err)
    }
}

func run() error {
    apiKey := os.Getenv("NEARAI_API_KEY")
    if apiKey == "" {
        return fmt.Errorf("set NEARAI_API_KEY first")
    }
    ctx, cancel := context.WithTimeout(context.Background(), 2*time.Minute)
    defer cancel()

    // Verify deployment evidence and the Gateway's Responses receipt.
    client, err := nearai.NewInferenceClient(nearai.InferenceOptions{
        ClientOptions: nearai.ClientOptions{
            APIKey: apiKey,
            BaseURL: "https://cloud-api.near.ai/v1",
        },
        E2EE: false,
    })
    if err != nil {
        return err
    }
    defer client.Close()

    ai := openai.NewClient(
        option.WithAPIKey(apiKey),
        option.WithBaseURL(client.BaseURL()),
        option.WithHTTPClient(client.HTTPClient()),
        option.WithMaxRetries(0),
    )
    response, err := ai.Responses.New(ctx, responses.ResponseNewParams{
        Model: "openai/gpt-6-astra",
        Input: responses.ResponseNewParamsInputUnion{OfString: openai.String("Hello!")},
        Store: openai.Bool(false),
    })
    if err != nil {
        return err
    }
    if response.ID == "" {
        return fmt.Errorf("response has no ID")
    }

    // Verify the exact bytes before displaying the answer.
    verified, err := client.VerifyResponse(ctx, response.ID)
    if err != nil {
        return err
    }
    fmt.Println(response.OutputText())
    fmt.Println("Verified signer:", verified.SignatureKind)
    return nil
}
```

JavaScript and Python also expose `client.responses.create()` directly on `InferenceClient`. Go provides `client.CreateResponse(ctx, request)`; Rust provides `client.create_response(request).await`.

## Receipt verification

Responses receipts use `signature_kind: gateway`. They authenticate the exact request and response bytes signed by the attested Gateway. A Gateway receipt does not establish that an attested model generated the response, even when preflight also verifies model evidence.

Use the top-level response `id` for verification. Receipt persistence is best-effort: a successful inference may have a temporarily unavailable receipt. Retry verification with the same ID when appropriate, without repeating inference. Response records expire after the configured TTL, which defaults to 60 minutes after full body consumption; verify before expiry or client cleanup.

## Streaming

Set `stream: true` (`stream=True` in Python) and consume the entire stream before verifying. Use the nested `event.response.id` from a response event such as `response.created`; output item IDs are not receipt IDs. Content displayed before verification succeeds is not yet signature-verified.

See complete streaming examples for [JavaScript](https://github.com/nearai/inference-sdk/blob/v0.2.0/examples/example-js/gateway/responses-openai-sdk.ts), [Python](https://github.com/nearai/inference-sdk/blob/v0.2.0/examples/example-py/gateway/responses_openai_sdk.py), [Rust](https://github.com/nearai/inference-sdk/blob/v0.2.0/examples/example-rs/src/bin/responses.rs), and [Go](https://github.com/nearai/inference-sdk/blob/v0.2.0/examples/example-go/gateway/responses/main.go).

## Supported behavior

- The Gateway transport supports `POST /v1/responses`, including JSON and SSE. Retrieval, deletion, cancellation, and history endpoints are outside this transport.
- Use client-managed history and `store: false`; see [Stateless Responses](/cloud/guides/stateless-responses) for multi-turn input and function-call replay.
- OHTTP is optional and requires Ed25519. Field-level E2EE and direct-endpoint Responses are rejected before network I/O.
- Provider `reasoning.encrypted_content` passes through as opaque data; it is separate from NEAR field encryption.
