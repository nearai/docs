NEAR AI Cloud is fully OpenAI-compatible. You can use the official OpenAI Python and JavaScript SDKs — or any other OpenAI-compatible client — without modification. The only change required is updating `base_url` / `baseURL` to the NEAR AI Cloud endpoint and supplying your NEAR AI API key. Every OpenAI-compatible method, parameter, and response shape works exactly as documented by OpenAI.

## Configuration

NEAR AI Cloud exposes two endpoint modes:

| Mode | Base URL | When to use |
|------|----------|-------------|
| **Gateway** | `https://cloud-api.near.ai/v1` | Routing across all catalog models; switch models without changing your base URL |
| **Direct Completions** | `https://{slug}.completions.near.ai/v1` | Lowest latency; TLS terminates directly inside the model's TEE |

Replace `{slug}` with the model-specific slug from the [Models](/cloud/models) page (for example, `qwen35-122b` for `Qwen/Qwen3.5-122B-A10B`).

**Generate an API key** in the [Developer Dashboard](https://cloud.near.ai) under **API Keys → Create API Key**. The key is shown only once — store it securely.

## Basic Setup

<Tabs>
  <Tab title="Python">
    ```python
    from openai import OpenAI

    client = OpenAI(
        base_url="https://cloud-api.near.ai/v1",
        api_key="YOUR_API_KEY",
    )

    response = client.chat.completions.create(
        model="zai-org/GLM-5.1-FP8",
        messages=[
            {"role": "system", "content": "You are a helpful assistant."},
            {"role": "user", "content": "What is a Trusted Execution Environment?"},
        ],
    )

    print(response.choices[0].message.content)
    ```
  </Tab>
  <Tab title="JavaScript / TypeScript">
    ```javascript
    import OpenAI from "openai";

    const client = new OpenAI({
      baseURL: "https://cloud-api.near.ai/v1",
      apiKey: "YOUR_API_KEY",
    });

    const response = await client.chat.completions.create({
      model: "zai-org/GLM-5.1-FP8",
      messages: [
        { role: "system", content: "You are a helpful assistant." },
        { role: "user", content: "What is a Trusted Execution Environment?" },
      ],
    });

    console.log(response.choices[0].message.content);
    ```
  </Tab>

## Async Usage (Python)

Use `AsyncOpenAI` for non-blocking calls in async Python applications:

```python
import asyncio
from openai import AsyncOpenAI

client = AsyncOpenAI(
    base_url="https://cloud-api.near.ai/v1",
    api_key="YOUR_API_KEY",
)

async def main():
    response = await client.chat.completions.create(
        model="zai-org/GLM-5.1-FP8",
        messages=[
            {"role": "user", "content": "Explain TEE attestation in one paragraph."},
        ],
    )
    print(response.choices[0].message.content)

asyncio.run(main())
```

## Streaming

Both the Python and JavaScript SDKs support streaming responses using the same OpenAI streaming interface.

<Tabs>
  <Tab title="Python">
    ```python
    from openai import OpenAI

    client = OpenAI(
        base_url="https://cloud-api.near.ai/v1",
        api_key="YOUR_API_KEY",
    )

    with client.chat.completions.stream(
        model="zai-org/GLM-5.1-FP8",
        messages=[
            {"role": "user", "content": "Write a short poem about private AI."},
        ],
    ) as stream:
        for text in stream.text_stream:
            print(text, end="", flush=True)
    ```
  </Tab>
  <Tab title="JavaScript / TypeScript">
    ```javascript
    import OpenAI from "openai";

    const client = new OpenAI({
      baseURL: "https://cloud-api.near.ai/v1",
      apiKey: "YOUR_API_KEY",
    });

    const stream = await client.chat.completions.create({
      model: "zai-org/GLM-5.1-FP8",
      messages: [
        { role: "user", content: "Write a short poem about private AI." },
      ],
      stream: true,
    });

    for await (const chunk of stream) {
      const delta = chunk.choices[0]?.delta?.content ?? "";
      process.stdout.write(delta);
    }
    ```
  </Tab>
</Tabs>

## Supported Features

NEAR AI Cloud supports all standard OpenAI-compatible endpoints as well as NEAR AI–specific extensions:

| Endpoint / Feature | Notes |
|--------------------|-------|
| `POST /v1/chat/completions` | Streaming, tool calling, structured outputs, vision |
| `POST /v1/completions` | Legacy text completions |
| `GET /v1/models` | Full model catalog with pricing and capability metadata |
| `POST /v1/embeddings` | Via gateway; see [Beyond Chat](/cloud/guides/specialized-endpoints) |
| `POST /v1/images/generations` | Image generation (FLUX.2-klein-4B and others) |
| `POST /v1/images/edits` | Image editing |
| `POST /v1/audio/transcriptions` | Whisper-based transcription |
| `GET/POST /v1/files` | File upload and retrieval |
| `POST /v1/conversations` | Persistent conversation threads |
| `POST /v1/responses` | Responses API (stateful, tool-enabled) |
| Streaming | Server-sent events on all inference endpoints |
| `POST /v1/rerank` | NEAR AI extension — document reranking |
| `POST /v1/privacy/classify` | NEAR AI extension — PII span detection |
| `POST /v1/privacy/redact` | NEAR AI extension — PII redaction |
| `GET /v1/attestation/report` | NEAR AI extension — hardware attestation |

## Files API

Use the OpenAI Files API to upload documents for use in subsequent inference requests.

<Tabs>
  <Tab title="Python">
    ```python
    from openai import OpenAI

    client = OpenAI(
        base_url="https://cloud-api.near.ai/v1",
        api_key="YOUR_API_KEY",
    )

    # Upload a file
    with open("document.pdf", "rb") as f:
        file_obj = client.files.create(file=f, purpose="assistants")

    print(file_obj.id)   # file-abc123

    # List uploaded files
    files = client.files.list()
    for f in files.data:
        print(f.id, f.filename, f.bytes)

    # Delete a file
    client.files.delete(file_obj.id)
    ```
  </Tab>
  <Tab title="JavaScript / TypeScript">
    ```javascript
    import OpenAI, { toFile } from "openai";
    import fs from "fs";

    const client = new OpenAI({
      baseURL: "https://cloud-api.near.ai/v1",
      apiKey: "YOUR_API_KEY",
    });

    // Upload a file
    const file = await client.files.create({
      file: await toFile(fs.createReadStream("document.pdf"), "document.pdf"),
      purpose: "assistants",
    });

    console.log(file.id); // file-abc123

    // List uploaded files
    const files = await client.files.list();
    for (const f of files.data) {
      console.log(f.id, f.filename, f.bytes);
    }

    // Delete a file
    await client.files.del(file.id);
    ```
  </Tab>
</Tabs>

## Conversations and Responses API

NEAR AI Cloud supports the stateful Conversations and Responses APIs for building multi-turn agents with persistent context.

<Tabs>
  <Tab title="Python">
    ```python
    from openai import OpenAI

    client = OpenAI(
        base_url="https://cloud-api.near.ai/v1",
        api_key="YOUR_API_KEY",
    )

    # Create a persistent conversation
    conversation = client.post("/v1/conversations", body={})
    conversation_id = conversation.json()["id"]

    # Create a response within the conversation
    response = client.post(
        "/v1/responses",
        body={
            "model": "zai-org/GLM-5.1-FP8",
            "conversation": {"id": conversation_id},
            "input": "Hello! What can you help me with?",
        },
    )
    print(response.json()["output"])

    # Continue the conversation using previous_response_id
    follow_up = client.post(
        "/v1/responses",
        body={
            "model": "zai-org/GLM-5.1-FP8",
            "previous_response_id": response.json()["id"],
            "input": "Tell me more about TEEs.",
        },
    )
    print(follow_up.json()["output"])
    ```
  </Tab>
  <Tab title="JavaScript / TypeScript">
    ```javascript
    import OpenAI from "openai";

    const client = new OpenAI({
      baseURL: "https://cloud-api.near.ai/v1",
      apiKey: "YOUR_API_KEY",
    });

    // Create a persistent conversation
    const conversationRes = await client.post("/v1/conversations", { body: {} });
    const conversationId = conversationRes.id;

    // Create a response within the conversation
    const response = await client.post("/v1/responses", {
      body: {
        model: "zai-org/GLM-5.1-FP8",
        conversation: { id: conversationId },
        input: "Hello! What can you help me with?",
      },
    });
    console.log(response.output);

    // Continue the conversation using previous_response_id
    const followUp = await client.post("/v1/responses", {
      body: {
        model: "zai-org/GLM-5.1-FP8",
        previous_response_id: response.id,
        input: "Tell me more about TEEs.",
      },
    });
    console.log(followUp.output);
    ```
  </Tab>
</Tabs>

## Environment Variables

Both the Python and JavaScript SDKs automatically read `OPENAI_BASE_URL` and `OPENAI_API_KEY` from the environment, so you can configure the client without passing values in code:

```bash
export OPENAI_BASE_URL="https://cloud-api.near.ai/v1"
export OPENAI_API_KEY="YOUR_API_KEY"
```

With these variables set, you can instantiate a client with no arguments:

<Tabs>
  <Tab title="Python">
    ```python
    from openai import OpenAI

    # Reads OPENAI_BASE_URL and OPENAI_API_KEY automatically
    client = OpenAI()

    response = client.chat.completions.create(
        model="zai-org/GLM-5.1-FP8",
        messages=[{"role": "user", "content": "Hello!"}],
    )
    print(response.choices[0].message.content)
    ```
  </Tab>
  <Tab title="JavaScript / TypeScript">
    ```javascript
    import OpenAI from "openai";

    // Reads OPENAI_BASE_URL and OPENAI_API_KEY automatically
    const client = new OpenAI();

    const response = await client.chat.completions.create({
      model: "zai-org/GLM-5.1-FP8",
      messages: [{ role: "user", content: "Hello!" }],
    });
    console.log(response.choices[0].message.content);
    ```
  </Tab>
</Tabs>

<Tip>
  Store your API key in a `.env` file or your CI/CD secrets vault and load it with a library such as `python-dotenv` or `dotenv`. Never commit keys to source control.
