[Continue](https://continue.dev) is an open-source coding assistant extension for VS Code and JetBrains. It supports any OpenAI-compatible provider through its `openai` provider type and a custom `apiBase` setting, so you can point it at NEAR AI Cloud without changing anything else in your workflow.

## Prerequisites

- Continue extension installed ([continue.dev](https://continue.dev))
- A NEAR AI Cloud API key from [cloud.near.ai](https://cloud.near.ai)

## Configure

<Steps>
  <Step title="Open your Continue config file">
    In VS Code, press `Cmd+Shift+P` (macOS) or `Ctrl+Shift+P` (Windows/Linux) and search for **Continue: Open config**. This opens `~/.continue/config.yaml` (or `config.json` if you are using the legacy format).

    In JetBrains, find the Continue plugin settings and click **Open config file**.
  </Step>
  <Step title="Add NEAR AI Cloud as a provider">
    Add a model entry under `models` using `provider: openai` and set `apiBase` to the NEAR AI Cloud gateway URL.

    <Tabs>
      <Tab title="config.yaml (recommended)">
        ```yaml title="~/.continue/config.yaml"
        name: My Config
        version: 0.0.1
        schema: v1

        models:
          - name: NEAR AI Cloud — GLM 5.2
            provider: openai
            model: z-ai/glm-5.2
            apiBase: https://cloud-api.near.ai/v1
            apiKey: $NEARAI_API_KEY
        ```

        Replace `$NEARAI_API_KEY` with your actual key, or use Continue's secrets mechanism to keep it out of the config file.
      </Tab>
      <Tab title="config.json (legacy)">
        ```json title="~/.continue/config.json"
        {
          "models": [
            {
              "title": "NEAR AI Cloud — GLM 5.2",
              "provider": "openai",
              "model": "z-ai/glm-5.2",
              "apiBase": "https://cloud-api.near.ai/v1",
              "apiKey": "YOUR_NEARAI_API_KEY"
            }
          ]
        }
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step title="Add more models (optional)">
    You can add multiple NEAR AI Cloud models to the `models` array. Each entry needs its own `name`, `model` (the model ID), and the shared `apiBase` and `apiKey`.

    ```yaml title="~/.continue/config.yaml"
    models:
      - name: NEAR AI — GLM 5.2
        provider: openai
        model: z-ai/glm-5.2
        apiBase: https://cloud-api.near.ai/v1
        apiKey: $NEARAI_API_KEY

      - name: NEAR AI — Qwen3.5-122B
        provider: openai
        model: Qwen/Qwen3.5-122B-A10B
        apiBase: https://cloud-api.near.ai/v1
        apiKey: $NEARAI_API_KEY
    ```

    See the [Models catalog](/cloud/models) or the [model discovery endpoint](/cloud/guides/integrations/model-discovery) for the full list of available model IDs.
  </Step>
  <Step title="Select the model in Continue">
    Save the config file. Continue automatically reloads when the file changes. Open the Continue panel in your IDE and click the model selector at the bottom to choose your NEAR AI Cloud model.
  </Step>
</Steps>

## Refresh Models

Continue does not auto-discover models from `/v1/models` in the OpenAI-compatible provider path — each model must be declared as a separate entry in `config.yaml`. Add new entries when NEAR AI Cloud adds new models you want to use.

## Quick Test

```bash
curl https://cloud-api.near.ai/v1/chat/completions \
  -H "Authorization: Bearer $NEARAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "z-ai/glm-5.2",
    "messages": [
      {
        "role": "user",
        "content": "Reply with one sentence confirming the model is reachable."
      }
    ],
    "max_tokens": 64
  }'
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| Model not appearing in Continue's selector | Confirm the config file was saved and Continue reloaded. Check the YAML/JSON for syntax errors — a single indentation mistake prevents the file from loading. |
| `401 Unauthorized` | Verify the `apiKey` value in your config. Generate a new key at [cloud.near.ai](https://cloud.near.ai) if needed. |
| `apiBase` field rejects the URL | Ensure the value is exactly `https://cloud-api.near.ai/v1` with no trailing slash. Do not include `/chat/completions`. |
| Model returns unexpected errors | Some models require a specific `model` ID format (e.g. `z-ai/glm-5.2`, not just `glm-5.2`). Copy the ID directly from [cloud.near.ai/models](https://cloud.near.ai/models). |
