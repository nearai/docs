[Aider](https://aider.chat) is an AI pair programming CLI that works with any OpenAI-compatible endpoint via environment variables. [Zed](https://zed.dev) is a high-performance code editor with built-in AI features that supports custom OpenAI-compatible providers through its settings file. Both integrate cleanly with NEAR AI Cloud.

## Aider

### Prerequisites

- Aider installed (`python -m pip install aider-install && aider-install`)
- A NEAR AI Cloud API key from [cloud.near.ai](https://cloud.near.ai)

### Configure

<Steps>
  <Step title="Set the environment variables">
    Aider reads the OpenAI base URL and API key from environment variables. Set both before running aider:

    <Tabs>
      <Tab title="macOS / Linux">
        ```bash
        export OPENAI_API_BASE=https://cloud-api.near.ai/v1
        export OPENAI_API_KEY=$NEARAI_API_KEY
        ```
      </Tab>
      <Tab title="Windows (cmd)">
        ```cmd
        setx OPENAI_API_BASE https://cloud-api.near.ai/v1
        setx OPENAI_API_KEY YOUR_NEARAI_API_KEY
        ```
        Restart your shell after running `setx` for the variables to take effect.
      </Tab>
    </Tabs>

    Alternatively, add both lines to a `.env` file in your project root or home directory — Aider loads `.env` automatically:

    ```ini title=".env"
    OPENAI_API_BASE=https://cloud-api.near.ai/v1
    OPENAI_API_KEY=YOUR_NEARAI_API_KEY
    ```
  </Step>
  <Step title="Run Aider with a NEAR AI Cloud model">
    Prefix the model ID with `openai/` so Aider routes the request to the OpenAI-compatible endpoint:

    ```bash
    cd /path/to/your/project
    aider --model openai/z-ai/glm-5.2
    ```

    You can use any model ID listed at [cloud.near.ai/models](https://cloud.near.ai/models):

    ```bash
    aider --model openai/Qwen/Qwen3.5-122B-A10B
    ```
  </Step>
  <Step title="Persist settings in .aider.conf.yml (optional)">
    To avoid passing `--model` on every invocation, add it to `.aider.conf.yml` in your project root or home directory:

    ```yaml title=".aider.conf.yml"
    openai-api-base: https://cloud-api.near.ai/v1
    openai-api-key: YOUR_NEARAI_API_KEY
    model: openai/z-ai/glm-5.2
    ```
  </Step>
</Steps>

### Refresh Models

Aider does not auto-discover models from `/v1/models`. Pass the model ID explicitly with `--model openai/<model-id>` each time, or set it permanently in `.aider.conf.yml`. You can list available NEAR AI Cloud model IDs with:

```bash
curl https://cloud-api.near.ai/v1/models \
  -H "Authorization: Bearer $NEARAI_API_KEY" | python3 -m json.tool
```

## Zed Editor

### Prerequisites

- Zed installed ([zed.dev](https://zed.dev))
- A NEAR AI Cloud API key from [cloud.near.ai](https://cloud.near.ai)

### Configure

<Steps>
  <Step title="Open Agent Settings">
    In Zed, open the command palette (`Cmd+Shift+P` / `Ctrl+Shift+P`) and run **agent: open settings**. This opens the **AI → LLM Providers** settings page.
  </Step>
  <Step title="Add an OpenAI-compatible provider">
    In the **LLM Providers** section, click **Add Provider** and choose **OpenAI Compatible**.

    Fill in:
    - **Provider name** — a display label, e.g. `NEAR AI Cloud`
    - **API URL** — `https://cloud-api.near.ai/v1`
    - **Model ID** — e.g. `z-ai/glm-5.2`
    - **Context window** — the model's context length (e.g. `131072`)

    Enter your API key in the key field — Zed stores it in the system keychain, not in `settings.json`.
  </Step>
  <Step title="Or configure directly in settings.json">
    You can also add the provider in your Zed `settings.json` (open with **zed: open settings file**):

    ```json title="settings.json"
    {
      "language_models": {
        "openai_compatible": {
          "near-ai-cloud": {
            "api_url": "https://cloud-api.near.ai/v1",
            "available_models": [
              {
                "name": "z-ai/glm-5.2",
                "display_name": "NEAR AI — GLM 5.2",
                "max_tokens": 131072
              },
              {
                "name": "Qwen/Qwen3.5-122B-A10B",
                "display_name": "NEAR AI — Qwen3.5-122B",
                "max_tokens": 131072
              }
            ]
          }
        }
      }
    }
    ```

    Store the API key separately. Zed reads the generated environment variable `NEAR_AI_CLOUD_API_KEY` (derived from the provider ID `near-ai-cloud` in upper snake case plus `_API_KEY`), or you can enter it in the Agent Settings UI where it will be stored in the system keychain.
  </Step>
  <Step title="Select the model in the Agent Panel">
    Open the Zed Agent Panel and click the model selector. Your NEAR AI Cloud models appear under the provider name you configured. Select one to activate it.
  </Step>
</Steps>

### Refresh Models

Zed does not auto-fetch `/v1/models` for OpenAI-compatible providers. Add new model entries to `available_models` in `settings.json` as needed, then restart Zed.

## Quick Test (both tools)

```bash
curl https://cloud-api.near.ai/v1/chat/completions \
  -H "Authorization: Bearer $NEARAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "z-ai/glm-5.2",
    "messages": [
      {
        "role": "user",
        "content": "Reply with one sentence confirming the model is reachable."
      }
    ],
    "max_tokens": 64
  }'
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| Aider: `Model not found` warning | Make sure the model ID is prefixed with `openai/` — e.g. `openai/z-ai/glm-5.2`. |
| Aider: `401 Unauthorized` | Verify `OPENAI_API_KEY` is set to your NEAR AI Cloud key and `OPENAI_API_BASE` is `https://cloud-api.near.ai/v1`. |
| Aider: `OPENAI_API_BASE` not respected | Aider loads `.env` from the project root and home directory. Confirm the file is saved and the variable name is exact. |
| Zed: model not in the Agent Panel selector | Check that the `name` field in `available_models` matches the exact model ID from [cloud.near.ai/models](https://cloud.near.ai/models). |
| Zed: `401` errors | Enter the API key in **Agent Settings → LLM Providers → NEAR AI Cloud** so Zed can store it in the system keychain. |
| Zed: `api_url` ends with `/chat/completions` | Remove the path — the `api_url` must be `https://cloud-api.near.ai/v1` only. |
