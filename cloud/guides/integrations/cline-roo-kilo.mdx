[Cline](https://github.com/cline/cline), [Roo Code](https://github.com/RooCodeInc/Roo-Code), and [Kilo Code](https://github.com/Kilo-Org/kilocode) are autonomous VS Code coding agents. All three share the same OpenAI-compatible provider settings shape, so the configuration steps are nearly identical across all three. Point any of them at NEAR AI Cloud by selecting the **OpenAI Compatible** provider and filling in the base URL and API key.

## Prerequisites

- One or more extensions installed from the VS Code Marketplace: [Cline](https://marketplace.visualstudio.com/items?itemName=saoudrizwan.claude-dev), [Roo Code](https://marketplace.visualstudio.com/items?itemName=RooVeterinaryInc.roo-cline), or [Kilo Code](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code)
- A NEAR AI Cloud API key from [cloud.near.ai](https://cloud.near.ai)

## Configure

The steps below apply to all three extensions. Screenshots show Cline, but the settings panel layout is the same in Roo Code and Kilo Code.

<Steps>
  <Step title="Open the extension settings panel">
    Click the extension icon in the VS Code Activity Bar to open the agent panel. Then click the **gear icon (⚙️)** at the top of the panel to open the settings/configuration view.
  </Step>
  <Step title="Select the OpenAI Compatible provider">
    In the **API Provider** dropdown, choose **OpenAI Compatible**.

    The form switches to show three fields:
    - **Base URL**
    - **API Key**
    - **Model ID**
  </Step>
  <Step title="Enter the NEAR AI Cloud connection details">
    Fill in the fields:

    | Field | Value |
    |---|---|
    | **Base URL** | `https://cloud-api.near.ai/v1` |
    | **API Key** | Your NEAR AI Cloud API key |
    | **Model ID** | A NEAR AI Cloud model ID — e.g. `z-ai/glm-5.2` |

    The extension automatically calls `/v1/models` after you enter the base URL and API key, and populates the model dropdown with available models. You can also type the model ID manually.
  </Step>
  <Step title="Configure Model Configuration (recommended)">
    Expand the **Model Configuration** section below the model field. For NEAR AI Cloud models, set at minimum:

    - **Context Window** — the model's actual context window (e.g. `131072` for GLM-5.2 or Qwen3.5-122B). Check [cloud.near.ai/models](https://cloud.near.ai/models) for the correct value. Setting this too low causes premature context truncation.
    - **Computer Use** — enable this to allow the agent to make tool calls and agentic edits. Without it, the extension treats the model as chat-only and agent actions silently fail.

    Leave **Image Support** off unless you are using a multimodal model such as `Qwen/Qwen3-VL-30B-Instruct`.
  </Step>
  <Step title="Verify and test">
    Click **Verify** (if shown) to confirm the base URL, key, and model ID resolve. Then send a simple prompt in a new task to confirm responses are coming back correctly before using the agent on real code.
  </Step>
</Steps>

## Refresh Models

After you enter the base URL and API key, Cline, Roo Code, and Kilo Code automatically query the NEAR AI Cloud `/v1/models` endpoint and populate the model dropdown. If new models don't appear, clear the base URL and API key fields, then re-enter them to trigger a fresh fetch.

## Quick Test

```bash
curl https://cloud-api.near.ai/v1/chat/completions \
  -H "Authorization: Bearer $NEARAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "z-ai/glm-5.2",
    "messages": [
      {
        "role": "user",
        "content": "Reply with one sentence confirming the model is reachable."
      }
    ],
    "max_tokens": 64
  }'
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| Model not listed in dropdown | Check that the base URL is exactly `https://cloud-api.near.ai/v1` and the API key is valid. Re-enter both to trigger a fresh model fetch. |
| `401 Unauthorized` | Regenerate your API key at [cloud.near.ai](https://cloud.near.ai) and re-enter it in the **API Key** field. |
| Base URL field shows `/chat/completions` | Remove the path suffix — the **Base URL** must be `https://cloud-api.near.ai/v1` only. |
| Agent actions silently fail | Enable **Computer Use** in Model Configuration. Without it the extension treats the model as chat-only. |
| Responses are cut off unexpectedly | Set **Context Window** in Model Configuration to the correct value for your model (e.g. `131072`). |
