Cursor supports any OpenAI-compatible provider through its **OpenAI Compatible** settings section. Once configured, you can select NEAR AI Cloud models from Cursor's model picker for chat, inline editing, and agentic tasks — while your prompts stay inside hardware-encrypted TEEs.

<Note>
  Cursor routes all API requests through its own backend servers, which means Cursor's Zero Data Retention policy does not apply when you use a custom API key. Your data handling is governed by NEAR AI Cloud's privacy policy, not Cursor's.
</Note>

## Prerequisites

- Cursor installed ([cursor.com](https://cursor.com))
- A NEAR AI Cloud API key from [cloud.near.ai](https://cloud.near.ai)

## Configure

<Steps>
  <Step title="Open Cursor Settings">
    Press `Cmd+Shift+P` (macOS) or `Ctrl+Shift+P` (Windows/Linux) to open the command palette. Search for **Cursor Settings** and select it, or click the gear icon in the bottom-left corner of the window.

    Navigate to the **Models** section in the sidebar.
  </Step>
  <Step title="Scroll to the OpenAI Compatible section">
    In the Models settings page, scroll down past the first-party provider sections (OpenAI, Anthropic, Google) until you reach **OpenAI Compatible**.

    You will see two fields:
    - **API Base URL**
    - **API Key**
  </Step>
  <Step title="Enter the NEAR AI Cloud credentials">
    Fill in the fields:

    | Field | Value |
    |---|---|
    | **API Base URL** | `https://cloud-api.near.ai/v1` |
    | **API Key** | Your NEAR AI Cloud API key |

    Click **Save** or press Enter. Cursor will attempt to verify the credentials.
  </Step>
  <Step title="Add a model">
    Still in the **OpenAI Compatible** section, click **Add Model** (or the **+** button next to the model list). Enter the model ID exactly as NEAR AI Cloud exposes it — for example:

    ```
    z-ai/glm-5.2
    ```

    You can find the full list of model IDs at [cloud.near.ai/models](https://cloud.near.ai/models) or by calling the [model discovery endpoint](/cloud/guides/integrations/model-discovery).

    Click **Add** to confirm.
  </Step>
  <Step title="Select your model">
    Open a Cursor chat or Composer window. Click the model selector dropdown and choose the model you just added (for example, `z-ai/glm-5.2`). Cursor will route subsequent requests to NEAR AI Cloud.
  </Step>
</Steps>

## Refresh Models

Cursor does not auto-fetch the `/v1/models` endpoint for OpenAI-compatible providers — you add models manually in the settings UI. Revisit **Cursor Settings → Models → OpenAI Compatible** and click **Add Model** whenever you want to add a new NEAR AI Cloud model. Check [cloud.near.ai/models](https://cloud.near.ai/models) for the latest model IDs.

## Quick Test

Verify the connection works before starting any real work:

```bash
curl https://cloud-api.near.ai/v1/chat/completions \
  -H "Authorization: Bearer $NEARAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "z-ai/glm-5.2",
    "messages": [
      {
        "role": "user",
        "content": "Reply with one sentence confirming the model is reachable."
      }
    ],
    "max_tokens": 64
  }'
```

A JSON response with a `choices[0].message.content` value confirms the connection is healthy.

## Troubleshooting

| Symptom | Fix |
|---|---|
| Model not appearing in the picker | Make sure you clicked **Add Model** and typed the full model ID (e.g. `z-ai/glm-5.2`). The model ID must match exactly. |
| `401 Unauthorized` error in Cursor | Re-enter your API key in the **OpenAI Compatible → API Key** field. Generate a new key at [cloud.near.ai](https://cloud.near.ai) if needed. |
| Base URL field includes `/chat/completions` | Remove the path — the **API Base URL** field must be `https://cloud-api.near.ai/v1` only. Cursor appends `/chat/completions` itself. |
| Requests succeed in curl but fail in Cursor | Cursor routes requests through its own servers. Check that your NEAR AI Cloud account has available credits. |
