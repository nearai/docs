Use these guides to connect third-party software to NEAR AI Cloud through its OpenAI-compatible API, or through its Anthropic Messages API for Claude Code.

Most clients need the same values:

| Setting | Value |
| --- | --- |
| Base URL | `https://cloud-api.near.ai/v1` |
| API key | A NEAR AI Cloud API key |
| Model ID | A model available from NEAR AI Cloud |

Claude Code is the exception: it takes `https://cloud-api.near.ai` without `/v1`. See the [Claude Code guide](/cloud/guides/integrations/claude-code).

If you have never used an API key before: create one under **API Keys** in the [NEAR AI Cloud Dashboard](https://cloud.near.ai/dashboard/organizations), then follow the guide for your tool. Each guide shows where the key goes.

## Model Discovery

NEAR AI Cloud can add new models over time. Use the [Model Discovery guide](/cloud/guides/integrations/model-discovery) to check the current Gateway model list and copy the right model ID into clients that do not refresh automatically.

```bash
curl https://cloud-api.near.ai/v1/models
```
