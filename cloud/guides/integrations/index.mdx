NEAR AI Cloud works with any OpenAI-compatible tool. Set the base URL to `https://cloud-api.near.ai/v1`, paste your API key from [cloud.near.ai](https://cloud.near.ai), and the tool will route requests through NEAR AI's gateway — giving you private, TEE-protected inference without changing how you work.

## Discovering Available Models

Every tool listed above can automatically populate its model list from the NEAR AI Cloud `/v1/models` endpoint. See the [Model Discovery guide](/cloud/guides/integrations/model-discovery) to learn how the endpoint works and how to point tools at it for automatic model detection.
