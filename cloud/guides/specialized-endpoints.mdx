NEAR AI Cloud is more than a chat API. The same gateway, the same API key, and the same TEE privacy guarantees cover a full suite of specialized inference endpoints — including text embeddings, document reranking, image generation, audio transcription, and PII detection. You can also reach any of these capabilities directly via per-model completions endpoints for the lowest possible latency.

## Embeddings

Generate dense vector representations of text using `Qwen/Qwen3-Embedding-0.6B`. The response follows the standard OpenAI embeddings format.

```bash
curl https://cloud-api.near.ai/v1/embeddings \
  -H "Authorization: Bearer $NEAR_AI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen3-Embedding-0.6B",
    "input": "NEAR AI Cloud runs inference inside Trusted Execution Environments."
  }'
```

The response contains a `data` array where each element has an `embedding` field (a list of floats) and an `index` corresponding to the position in the input. Pass an array of strings to `input` to embed multiple texts in a single request.

## Reranking

Reorder a set of candidate documents by relevance to a query using `Qwen/Qwen3-Reranker-0.6B`. The `POST /v1/rerank` endpoint accepts a `query`, a list of `documents`, and optional `top_n` and `return_documents` parameters.

```bash
curl https://cloud-api.near.ai/v1/rerank \
  -H "Authorization: Bearer $NEAR_AI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen3-Reranker-0.6B",
    "query": "What is a Trusted Execution Environment?",
    "documents": [
      "A TEE is a secure area of a processor that protects code and data.",
      "The weather in San Francisco is mild and foggy.",
      "Hardware attestation allows remote verification of enclave integrity."
    ],
    "top_n": 2,
    "return_documents": true
  }'
```

The response contains a `results` array sorted by `relevance_score` (higher is more relevant), each with the document `index` in the original input list:

```json
{
  "id": "rerank-abc123",
  "model": "Qwen/Qwen3-Reranker-0.6B",
  "results": [
    {
      "index": 0,
      "relevance_score": 0.9821,
      "document": "A TEE is a secure area of a processor that protects code and data."
    },
    {
      "index": 2,
      "relevance_score": 0.8734,
      "document": "Hardware attestation allows remote verification of enclave integrity."
    }
  ]
}
```

## Image Generation

Generate images from text prompts using `black-forest-labs/FLUX.2-klein-4B` (or any other image model in the catalog). The endpoint follows the OpenAI images API.

```bash
curl https://cloud-api.near.ai/v1/images/generations \
  -H "Authorization: Bearer $NEAR_AI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "black-forest-labs/FLUX.2-klein-4B",
    "prompt": "A glowing CPU enclave floating in deep space, digital art",
    "n": 1,
    "size": "1024x1024",
    "response_format": "b64_json"
  }'
```

The response contains a `data` array of image objects. When `response_format` is `b64_json`, each object includes a `b64_json` field with the base64-encoded PNG. To edit an existing image, use `POST /v1/images/edits` with a multipart form upload.

## Audio Transcription

Transcribe audio files to text using `openai/whisper-large-v3`. Send a multipart form upload with the audio file and the model name.

```bash
curl https://cloud-api.near.ai/v1/audio/transcriptions \
  -H "Authorization: Bearer $NEAR_AI_KEY" \
  -F "file=@recording.mp3" \
  -F "model=openai/whisper-large-v3" \
  -F "response_format=json"
```

The response includes the transcribed `text` along with optional `language`, `duration`, `segments`, and `words` fields depending on the `response_format` and `timestamp_granularities` you request:

```json
{
  "text": "NEAR AI Cloud runs your inference inside a Trusted Execution Environment.",
  "language": "en",
  "duration": 4.2
}
```

## PII Detection and Redaction

### Classify — Detect PII Spans

`POST /v1/privacy/classify` identifies personally identifiable information (PII) in one or more input strings, returning a list of detected spans with categories and confidence scores.

```bash
curl https://cloud-api.near.ai/v1/privacy/classify \
  -H "Authorization: Bearer $NEAR_AI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/privacy-filter",
    "input": "Contact Alice at alice@example.com or call 555-867-5309.",
    "threshold": 0.8
  }'
```

The response includes a `data` array with one entry per input string. Each entry contains a `spans` array identifying detected PII — including character offsets, category labels (e.g. `EMAIL`, `PHONE_NUMBER`, `PERSON`), and confidence scores.

```json
{
  "model": "openai/privacy-filter",
  "data": [
    {
      "spans": [
        { "start": 11, "end": 27, "category": "EMAIL", "score": 0.997 },
        { "start": 39, "end": 51, "category": "PHONE_NUMBER", "score": 0.993 },
        { "start": 8,  "end": 13, "category": "PERSON", "score": 0.981 }
      ]
    }
  ]
}
```

### Redact — Replace PII with Placeholders

`POST /v1/privacy/redact` (gateway only) replaces detected PII in each input string with category-labeled placeholders.

```bash
curl https://cloud-api.near.ai/v1/privacy/redact \
  -H "Authorization: Bearer $NEAR_AI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/privacy-filter",
    "input": "Contact Alice at alice@example.com or call 555-867-5309.",
    "threshold": 0.8
  }'
```

The response `data` array contains per-input objects with a `redacted` field holding the sanitized string:

```json
{
  "model": "openai/privacy-filter",
  "data": [
    {
      "index": 0,
      "redacted": "Contact [PERSON] at [EMAIL] or call [PHONE_NUMBER]."
    }
  ]
}
```

<Note>
  Both `input` fields accept either a single string or an array of strings. When you pass an array, each element is classified or redacted independently and the results are returned in the same order.
</Note>

## Vision (Image Input)

Models that support image input accept images using the standard OpenAI multi-modal message format — set `content` to an array containing `text` and `image_url` parts. `Qwen/Qwen3-VL-30B-A3B-Instruct` is one example of a vision-capable model on NEAR AI Cloud.

To discover which models support image input, call `GET /v1/models` and inspect the `input_modalities` field on each model object. Models with `"image"` listed in `input_modalities` accept image content parts.

```bash
curl https://cloud-api.near.ai/v1/chat/completions \
  -H "Authorization: Bearer $NEAR_AI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen3-VL-30B-A3B-Instruct",
    "messages": [
      {
        "role": "user",
        "content": [
          { "type": "text", "text": "Describe what you see in this image." },
          { "type": "image_url", "image_url": { "url": "https://example.com/photo.jpg" } }
        ]
      }
    ]
  }'
```

## Direct Completions Endpoints

All specialized endpoints are also available through model-specific direct completions URLs, which terminate TLS directly inside the model's TEE:

| Model | Direct Completions Base URL |
|-------|-----------------------------|
| `Qwen/Qwen3-Embedding-0.6B` | `https://qwen3-embedding.completions.near.ai/v1` |
| `Qwen/Qwen3-Reranker-0.6B` | `https://qwen3-reranker.completions.near.ai/v1` |
| `black-forest-labs/FLUX.2-klein-4B` | `https://flux2-klein.completions.near.ai/v1` |

Use the same API key and request format — just swap the base URL. Find slugs for all models on the [Models](/cloud/models) page.
