# SDK language icons

JavaScript, Python, Rust, and Go icons are from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/4bfa9da744e2c06928047314ce30dc5c8d1ad759/icons), revision `4bfa9da744e2c06928047314ce30dc5c8d1ad759`, under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/4bfa9da744e2c06928047314ce30dc5c8d1ad759/LICENSE.md).

The original paths and 24 × 24 view boxes are preserved. A light monochrome fill (`#e5e7eb`) makes the local SVG files visible on the site's dark theme. SDK sidebar entries and overview cards share these assets.
