# SDK language icons

Original language artwork, used without recoloring:

- JavaScript: [JSConf community logo](https://github.com/voodootikigod/logo.js/blob/1544bdeed6d618a6cfe4f0650d04ab8d9cfa76d9/js.svg), MIT. The SVG retains its copyright and license notice.
- Python: [Python Software Foundation logo](https://www.python.org/community/logos/), from the linked [logo-only SVG](https://s3.dualstack.us-east-2.amazonaws.com/pythondotorg-assets/media/files/python-logo-only.svg), subject to the [PSF trademark policy](https://www.python.org/psf/trademarks/). A matching `viewBox` was added for proportional scaling; the artwork and colors are unchanged.
- Rust: © Rust Foundation, [rust-textured logo](https://github.com/rust-lang/rust-artwork/blob/7b54b6689dc310db2f301d7bcda847f016bd447c/logo/rusty/rust-logo-256x256.png), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), unmodified.
- Go: [Go project blue logo](https://go.dev/images/go-logo-blue.svg), subject to the [Go brand guidelines](https://go.dev/brand).

The SDK sidebar, overview cards, and verification example tabs share these local assets.
